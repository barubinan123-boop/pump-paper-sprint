A paper-trading bot for make.fun's "Pump.fun Paper Sprint: Any Bot Can Win" bounty. It rides short bursts of buying momentum on pump.fun bonding curves — entering when a coin's price jumps on buy-dominated tape — and exits fast with a take-profit, a stop-loss, a trailing stop and a maximum hold time, so one bad coin can never sink the run. Fully deterministic and paper-only: it speaks the agent-fun/replay/v2 protocol on stdin/stdout and never touches real funds.

## Run it

```sh
node main.ts
```

The harness feeds it `hello`, `batch` and `done` messages as newline-delimited JSON on stdin; the bot answers each batch with one `reply` line of orders on stdout. Node 22 or later (it runs TypeScript directly).
